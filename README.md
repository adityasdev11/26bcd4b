# 26bcd4b
Quiz Game
Introduction:
This C application is a console-based quiz that displays multiple-choice questions, accepts the user’s answers and calculates the final score. It is designed as a simple, interactive way to test basic knowledge of C programming while practising the fundamentals of the language.
The program shows each question with four options, asks the user to enter the option number, and immediately tells whether the answer is correct. If the answer is wrong, the correct option is displayed. At the end of the quiz, the total score, the percentage and a short performance message are shown.
